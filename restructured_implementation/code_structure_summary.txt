================================================================================
RESTRUCTURED IMPLEMENTATION - CODE STRUCTURE & PIPELINE SUMMARY
================================================================================

OVERVIEW
--------
This folder contains the modular implementation of the 5-dimensional PPG +
Triaxial Accelerometer Heart Signal Reconstruction and Joint Bayesian
Hyperparameter Optimization pipeline. Every 8-second window (N = 1000 samples
at fs = 125 Hz) is processed individually to match the test-time evaluation
protocol, while cross-validation splits are strictly grouped by participant/
recording session to prevent data leakage.

DIRECTORY STRUCTURE
-------------------
restructured_implementation/
├── __init__.py                  # Package exports for all pipeline & optimization modules
├── dataset_preparation.py       # .ts loader, participant detection, Subject-Wise Group K-Fold
├── preprocessing.py             # Butterworth bandpass (30-240 BPM / 0.5-4.0 Hz) & normalization
├── reference_construction.py    # MISO delay-line regressor matrix U construction (build_U)
├── LMS_algorithms.py            # Standard LMS, NLMS, VS-LMS, and Late-Fusion bucket function
├── fusion.py                    # Spectral SNR estimation & SNR-Weighted Late Fusion
├── bpm_detection.py             # Zero-Padded Periodogram, Elgendi Systolic Peak, Objective Function
├── pipeline.py                  # Window-level signal reconstruction & HeartRateEstimatorModel
├── optimization.py              # 2-Phase Conditional TPE Optimization with Early Fold Pruning
├── code_structure_summary.txt   # This architecture and module reference summary
└── tests_on_dataset/
    └── participant_split.py     # Dataset ordering and participant boundary verification script

--------------------------------------------------------------------------------
1. DATASET PREPARATION & SUBJECT-WISE VALIDATION (dataset_preparation.py)
--------------------------------------------------------------------------------
- `load_ts(path)`:
  Reads multivariate .ts files and returns `X` of shape (n_windows, 5, 1000)
  with channels [ppg1, ppg2, accx, accy, accz] and ground-truth BPM `y` (n_windows,).
- `split_participants(X, step=250, tol=1e-3)`:
  Identifies contiguous recording sessions by checking the 750-sample overlap
  between consecutive windows without merging windows.
- `get_participant_groups(X, step=250, tol=1e-3)`:
  Returns an integer array `groups` of shape (n_windows,) with the participant ID
  for each individual window.
- `subject_wise_group_kfold(X, n_splits=5, ...)`:
  Partitions window indices into K balanced folds strictly grouped by participant ID
  so that all windows of a given subject stay in the same fold (zero data leakage).

--------------------------------------------------------------------------------
2. PREPROCESSING (preprocessing.py)
--------------------------------------------------------------------------------
- `bandpass(x, lo=0.5, hi=4.0, fs=125, order=4, causal=True)`:
  Applies a 4th-order Butterworth bandpass filter over the cardiac frequency band
  0.5 Hz - 4.0 Hz (corresponding to 30 BPM - 240 BPM). Automatically converts
  BPM cutoffs to Hz if values >= fs / 2 are passed.
- `normalize_amplitude(x, eps=1e-8)`:
  Zero-centers and scales each channel to unit standard deviation along the time axis.
- `preprocess_signal(x, ...)`:
  Filters and normalizes a single 5D window (5, N) and splits it into
  `(ppg1, ppg2, acc)` of shapes (N,), (N,), and (3, N).

--------------------------------------------------------------------------------
3. MISO REFERENCE SIGNAL CONSTRUCTION (reference_construction.py)
--------------------------------------------------------------------------------
- `build_U(acc, M)`:
  Constructs the (N, 3*M) spatio-temporal delay matrix `U` from the 3-axis
  accelerometer reference `acc` so that at sample `n`:
      m_hat[n] = sum_{k=1}^{3} w_k^T[n] a_k[n] = w^T[n] U[n]

--------------------------------------------------------------------------------
4. ADAPTIVE LMS ALGORITHMS & LATE FUSION BUCKET (LMS_algorithms.py & fusion.py)
--------------------------------------------------------------------------------
- `standard_lms(d, acc, M, mu=None, my=None)`:
  Standard MISO LMS with fixed step size `mu` and filter order `M`:
      w[n+1] = w[n] + mu * e[n] * a[n]
- `nlms(d, acc, M, mu=0.1, delta=1e-6, my=None)`:
  Normalized MISO LMS with step size `mu`, filter order `M`, and regularization `delta`:
      w[n+1] = w[n] + (mu / (delta + ||a[n]||^2)) * e[n] * a[n]
- `vs_lms(d, acc, M, mu_max=None, mu_min=1e-5, alpha=0.97, gamma=1e-3)`:
  Kwong & Johnston Variable Step-Size MISO LMS:
      mu'[n+1] = alpha * mu[n] + gamma * e^2[n]
      mu[n+1]  = clip(mu'[n+1], mu_min, mu_max)
- `estimate_cardiac_snr(sig, ...)` & `snr_weighted_late_fusion(e1, e2, ...)`:
  Computes in-band spectral SNR around the dominant cardiac peak (and 2nd harmonic)
  and fuses the two parallel-filtered PPG channels via SNR-weighted averaging:
      e_fused[n] = (SNR_1 / (SNR_1 + SNR_2)) * e_1[n] + (SNR_2 / (SNR_1 + SNR_2)) * e_2[n]
- `lms_bucket(ppg1, ppg2, acc, algorithm='standard_lms', M=16, **hyperparams)`:
  Bucket function that runs the selected LMS variant in parallel on `ppg1` and `ppg2`
  and returns the SNR-weighted Late-Fused cardiac signal `e_fused`.

--------------------------------------------------------------------------------
5. HEART RATE ESTIMATION & OBJECTIVE FUNCTION (bpm_detection.py)
--------------------------------------------------------------------------------
- `zero_padded_periodogram_bpm(x, fs=125, nfft=8192, lo=0.5, hi=4.0, window_type='hann')`:
  Tapers the N-sample window, explicitly zero-pads with `nfft - N` zeros, computes
  the periodogram, and converts the cardiac-band peak frequency to BPM (`60 * f_max`).
- `elgendi_systolic_peak_bpm(x, fs=125, w1_sec=0.111, w2_sec=0.667, beta_offset=0.02, ...)`:
  Elgendi's two-moving-average systolic peak detector (`MA_peak` over W1 and `MA_beat`
  over W2 on the squared positive signal with threshold offset `beta_offset * mean(S)`).
  Extracts systolic peaks and computes BPM from the median inter-beat interval.
- `estimate_bpm_window(e_window, hr_algorithm='periodogram', **hr_params)`:
  Selector bucket function for the HR detector and its sub-parameters.
- `objective_function(bpm_estimated, bpm_true)`:
  Computes the Mean Absolute Error (AAE in BPM) across windows.

--------------------------------------------------------------------------------
6. JOINT 2-PHASE TPE OPTIMIZATION WITH EARLY PRUNING (optimization.py)
--------------------------------------------------------------------------------
- Conditional Tree Search Space (`CONDITIONAL_SEARCH_SPACE`):
  1. Categorical choices:
     * `lms_algorithm` in {'standard_lms', 'nlms', 'vs_lms'}
     * `hr_algorithm`  in {'periodogram', 'elgendi'}
  2. Conditioned sub-parameters:
     * `standard_lms` -> `M` in [4, 48], `mu` in [1e-5, 5e-2]
     * `nlms`         -> `M` in [4, 48], `mu` in [1e-3, 1.5], `delta` in [1e-7, 1e-1]
     * `vs_lms`       -> `M` in [4, 48], `mu_max`, `mu_min`, `alpha`, `gamma`
     * `periodogram`  -> `nfft` in {4096, 8192, 16384}, `window_type` in {'hann', 'hamming', 'blackman'}
     * `elgendi`      -> `w1_sec` in [0.08, 0.16], `w2_sec` in [0.55, 0.85], `beta_offset` in [0.005, 0.10]
- `ConditionalTPE`:
  Tree-structured Parzen Estimator modeling `l(theta)` and `g(theta)` over the
  hierarchical search space and maximizing Expected Improvement `l(theta) / g(theta)`.
- `run_phase1_snr_screening(...)`:
  Phase 1 decoupled fast screening of the LMS filter subtree using `estimate_cardiac_snr`
  as a fast spectral SNR proxy.
- `run_phase2_tpe_optimization(...)` & `MedianFoldPruner`:
  Phase 2 end-to-end joint TPE optimization seeded with Phase 1's top LMS filters,
  evaluated via Subject-Wise Group K-Fold CV with early pruning across folds.
- `optimize_hr_pipeline(X, y, ...)`:
  Executes the full 2-phase optimization and returns `best_model` (`HeartRateEstimatorModel`),
  `best_hyperparameters`, and `best_score` (AAE in BPM).
