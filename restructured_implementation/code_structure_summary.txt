================================================================================
RESTRUCTURED IMPLEMENTATION - CODE STRUCTURE & PIPELINE SUMMARY
================================================================================

OVERVIEW
--------
This folder contains the modular implementation of the 5-dimensional PPG +
Triaxial Accelerometer Heart Signal Reconstruction and Joint Bayesian
Hyperparameter Optimization pipeline. Every 8-second window (N = 1000 samples
at fs = 125 Hz) is processed individually in a single forward pass to match the
test-time evaluation protocol, while cross-validation splits are strictly grouped
by participant/recording session to prevent data leakage.

DIRECTORY STRUCTURE
-------------------
restructured_implementation/
├── __init__.py                  # Package exports for all pipeline & optimization modules
├── dataset_preparation.py       # .ts loader, participant detection, Subject-Wise Group K-Fold
├── preprocessing.py             # Zero-phase Butterworth bandpass, 4th acc_mag channel & normalization
├── reference_construction.py    # 4-channel MISO delay-line regressor matrix U construction (build_U)
├── LMS_algorithms.py            # Single-pass Standard LMS, NLMS, VS-LMS, and Late-Fusion bucket
├── fusion.py                    # Motion-suppressed spectral SNR estimation & SNR-Weighted Late Fusion
├── bpm_detection.py             # Motion-Suppressed Harmonic Periodogram, Elgendi Peak, Objective Function
├── pipeline.py                  # Window-level signal reconstruction & HeartRateEstimatorModel
├── optimization.py              # 2-Phase Conditional TPE Optimization with Early Fold Pruning
├── pipeline_optimization_and_evaluation.ipynb # Notebook: pipeline docs, TPE optimization & visualizations

--------------------------------------------------------------------------------
1. DATASET PREPARATION & SUBJECT-WISE VALIDATION (dataset_preparation.py)
--------------------------------------------------------------------------------
- `load_ts(path)`:
  Reads multivariate .ts files and returns `X` of shape (n_windows, 5, 1000)
  with channels [ppg1, ppg2, accx, accy, accz] and ground-truth BPM `y` (n_windows,).
- `split_participants(X, step=250, tol=1e-3)`:
  Identifies contiguous recording sessions by checking the 750-sample overlap
  between consecutive windows without merging windows.
- `get_participant_groups(X, step=250, tol=1e-3)`:
  Returns an integer array `groups` of shape (n_windows,) with the participant ID
  for each individual window.
- `subject_wise_group_kfold(X, n_splits=5, ...)`:
  Partitions window indices into K balanced folds strictly grouped by participant ID
  so that all windows of a given subject stay in the same fold (zero data leakage).

--------------------------------------------------------------------------------
2. PREPROCESSING & 4TH ACCELEROMETER CHANNEL (preprocessing.py)
--------------------------------------------------------------------------------
- `bandpass(x, lo=0.5, hi=4.0, fs=125, order=3, causal=False)`:
  Applies a 3rd-order Butterworth bandpass filter over the cardiac frequency band
  0.5 Hz - 4.0 Hz (30 BPM - 240 BPM):
  * When `causal=False` (default): Uses `sosfiltfilt(..., padtype="odd", padlen=min(250, N-1))`
    to eliminate startup ringing transients and preserve zero-phase alignment
    between PPG and accelerometer channels.
  * When `causal=True`: Scales initial filter states `sosfilt_zi(sos)` by the first
    sample `x[..., :1]` to prevent step-response ringing from zero.
- `normalize_amplitude(x, eps=1e-8)`:
  Zero-centers and scales each channel to unit standard deviation along `axis=-1`.
- `prepare_channels(window, fs=125, lo=0.5, hi=4.0, order=3, causal=False)`:
  Computes the 4th non-linear accelerometer magnitude reference channel from the raw
  triaxial accelerometer *before* bandpass filtering:
      acc_mag = sqrt(accx^2 + accy^2 + accz^2)
  Stacks all 6 channels `[ppg1, ppg2, accx, accy, accz, acc_mag]`, applies
  `bandpass` and `normalize_amplitude`, and returns `ppg_norm` of shape `(2, N)`
  and `acc_norm` of shape `(4, N)`.

--------------------------------------------------------------------------------
3. MISO REFERENCE SIGNAL CONSTRUCTION (reference_construction.py)
--------------------------------------------------------------------------------
- `build_U(acc, M, pad_mode="edge")`:
  Constructs the `(N, 4*M)` spatio-temporal delay matrix `U` from the K=4
  normalized accelerometer channels (`accx, accy, accz, acc_mag`), pre-padding
  the pre-window delay history (`n < M - 1`) with edge/reflection or zero values
  so that at sample `n`:
      m_hat[n] = sum_{k=1}^{4} w_k^T[n] a_k[n] = w^T[n] U[n]

--------------------------------------------------------------------------------
4. SINGLE-PASS ADAPTIVE LMS ALGORITHMS & LATE FUSION (LMS_algorithms.py & fusion.py)
--------------------------------------------------------------------------------
All LMS algorithms perform a single forward pass from n = 0 to N - 1 starting
from `w_init` (defaulting to zeros of shape `(4*M,)`):
- `standard_lms(d, acc, M, mu=None, my=None, w_init=None, U=None)`:
  Standard MISO LMS with fixed step size `mu` and filter order `M`:
      w[n+1] = w[n] + mu * e[n] * a[n]
- `nlms(d, acc, M, mu=0.1, delta=1e-3, my=None, w_init=None, U=None)`:
  Normalized MISO LMS with step size `mu`, filter order `M`, and regularization `delta`:
      w[n+1] = w[n] + (mu / (delta + ||a[n]||^2)) * e[n] * a[n]
- `vs_lms(d, acc, M, mu_max=None, mu_min=1e-4, alpha=0.97, gamma=1e-3, w_init=None, U=None)`:
  Kwong & Johnston Variable Step-Size MISO LMS:
      mu'[n+1] = alpha * mu[n] + gamma * e^2[n]
      mu[n+1]  = clip(mu'[n+1], mu_min, mu_max)
- `estimate_cardiac_snr(sig, acc=None, ...)` & `snr_weighted_late_fusion(e1, e2, acc=None, ...)`:
  Computes the normalized PSD of `e1`, `e2`, and the mean normalized PSD of the 4
  accelerometer channels `P_acc(f)` in `[0.5, 4.0] Hz`. Penalizes residual motion
  peaks via:
      S_i(f) = P_ei(f) * np.maximum(0.05, 1.0 - 0.6 * P_acc(f))
  and computes `SNR_i` around the dominant peak of `S_i(f)` (plus its 2nd harmonic)
  divided by remaining in-band noise power to weight `e1[n]` and `e2[n]`.
- `lms_bucket(ppg1, ppg2, acc, algorithm='standard_lms', M=16, w_init=None, **hyperparams)`:
  Runs the selected single-pass LMS variant in parallel on `ppg1` and `ppg2` and
  returns the motion-suppressed SNR-weighted Late-Fused cardiac signal `e_fused`.

--------------------------------------------------------------------------------
5. HEART RATE ESTIMATION & OBJECTIVE FUNCTION (bpm_detection.py)
--------------------------------------------------------------------------------
- `motion_suppressed_periodogram_bpm(e_fused, acc_norm, fs=125, nfft=16384, window_type='hamming', suppression_alpha=0.6, harmonic_weight=0.35)`:
  1. Computes normalized PSD of `e_fused` and mean normalized PSD of the 4
     accelerometer channels `acc_norm` in `[0.5, 4.0] Hz`.
  2. Applies soft spectral subtraction:
         clean_score(f) = psd_e_band(f) * np.maximum(0.05, 1.0 - suppression_alpha * psd_acc_mean(f))
  3. Reinforces frequencies supported by a 2nd cardiac harmonic at `2f`:
         score(f) = clean_score(f) * (1.0 + harmonic_weight * psd_e_norm(2f))
  4. Returns `60.0 * freqs_band[np.argmax(score)]`.
- `zero_padded_periodogram_bpm(x, fs=125, nfft=16384, ..., acc_norm=None, suppression_alpha=0.6, harmonic_weight=0.35)`:
  Delegates to `motion_suppressed_periodogram_bpm` when `acc_norm` is provided, or
  computes a harmonic-reinforced zero-padded periodogram when `acc_norm is None`.
- `elgendi_systolic_peak_bpm(x, fs=125, w1_sec=0.111, w2_sec=0.667, beta_offset=0.02, ..., acc_norm=None)`:
  Elgendi's two-moving-average systolic peak detector with median IBI BPM estimation
  and fallback to `motion_suppressed_periodogram_bpm` if fewer than 2 peaks are found.
- `estimate_bpm_window(e_window, hr_algorithm='periodogram', acc_norm=None, **hr_params)`:
  Selector bucket function for the HR detector and its sub-parameters.
- `objective_function(bpm_estimated, bpm_true, rmse_weight=0.35, outlier_threshold=10.0, outlier_weight=0.50)`:
  Outlier-penalized composite objective combining AAE, RMSE, and a quadratic/linear
  penalty on errors exceeding `outlier_threshold` (10 BPM).

--------------------------------------------------------------------------------
6. JOINT 2-PHASE TPE OPTIMIZATION WITH EARLY PRUNING (optimization.py)
--------------------------------------------------------------------------------
- Conditional Tree Search Space (`CONDITIONAL_SEARCH_SPACE`, `MAX_M = 24`):
  1. Categorical choices:
     * `lms_algorithm` in {'standard_lms', 'nlms', 'vs_lms'}
     * `hr_algorithm`  in {'periodogram', 'elgendi'}
  2. Conditioned sub-parameters (scaled for single 1000-sample pass with 4M taps):
     * `standard_lms` -> `M` in [8, 24], `mu` in [5e-4, 0.02]
     * `nlms`         -> `M` in [8, 24], `mu` in [0.05, 0.8], `delta` in [1e-4, 1e-1]
     * `vs_lms`       -> `M` in [8, 24], `mu_max` in [0.005, 0.08], `mu_min` in [1e-4, 0.005],
                         `alpha` in [0.90, 0.995], `gamma` in [1e-4, 1e-2]
     * `periodogram`  -> `nfft` in {4096, 8192, 16384}, `window_type` in {'hann', 'hamming', 'blackman'},
                         `suppression_alpha` in [0.2, 0.85], `harmonic_weight` in [0.1, 0.6]
     * `elgendi`      -> `w1_sec` in [0.08, 0.16], `w2_sec` in [0.55, 0.85], `beta_offset` in [0.005, 0.10]
- `preprocess_dataset_windows(X, ...)`:
  Precomputes `prepare_channels` (`ppg1, ppg2, acc_norm`) and the maximal 3D delay
  tensor `U_max_3d` of shape `(N, 4, 24)` once per window so any filter order `M <= 24`
  is extracted by slicing `U_max_3d[:, :, :M].reshape(N, 4*M)`.
- `run_phase1_snr_screening(...)` & `run_phase2_tpe_optimization(...)`:
  2-phase TPE optimization with motion-suppressed SNR screening (Phase 1) and
  Subject-Wise Group K-Fold CV with `MedianFoldPruner` (Phase 2).
